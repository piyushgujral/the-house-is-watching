# The House Is Watching — Game Design V0.1

## Goal
Prove the smallest version of the game's core loop before spending money or building expensive systems.

## Core loop
1. Enter the house.
2. Explore.
3. Find the fuse.
4. Interact with it.
5. The house changes.
6. Reach the exit.

## V0.1 player experience
- Single-player browser prototype.
- Desktop keyboard and basic mobile touch controls.
- One compact house scene.
- One collectible/interactive objective: the fuse.
- One supernatural event after the fuse is found.
- One exit.

## Design principle
The game should eventually be recognizable as social horror, not a Pacify clone. The long-term differentiator is a house that changes and can imitate or mislead players.

## Future multiplayer direction
Target 1–4 players with cross-platform play where practical. Multiplayer is intentionally postponed until the single-player loop is fun and stable.

## Future systems
- Randomized objective locations.
- Dynamic room/hallway changes.
- Entity behavior states: watching, hunting, possession.
- Player rescue/downed state.
- Voice and social deception mechanics.
- Replayable events.

## Monetization rule
No ads, subscriptions, purchases, crypto, or NFT systems in V0.1. Monetization comes only after external playtesting demonstrates retention.
